Three distinct release hazards, each measured rather than reasoned about:

**R1 — the uncovered changeset, fail-closed in both directions.** #559's changeset landing *before* the
recut makes `check:release-note-coverage` exit 1 and name it. Landing *after* makes coverage stand aside
(the release would publish `core@0.28.1`) and `check:release-note` exit 1 instead. Either way it cannot
slip in; the route decides whether the cost is one coverage id or a whole new 0.28.1 note. Note the
near-miss that makes this easy to misread by eye: the 0.28.0 note *does* list
`segmented-control-keeps-selection`, a different changeset with a similar name.

**R2 — the missing-changeset hole, and it is open.** A published package's *source* can change with no
changeset at all and every release gate stays green, because the gates only ask whether a **pending
changeset** is described in the curated note — never whether a source change has one. **#640, #641,
#642, #631 and #636** are live instances: all five change `packages/ui/**` or `packages/ui-swiftui/**`
or `packages/ui-angular/**` and none carries a changeset. If any lands before the release, an
accessibility or motion behaviour change ships inside 0.28.0 / 0.26.3 with no changelog line and no
release-note sentence.

**R3 — one of #638's own six controls does not fire.** Deleting a Progress compatibility description
from the curated note leaves every gate green. Four of the five controls §3 named do fire; that one
does not.

## 6. Missing CI, and why

`ci.yml` is `pull_request: branches: [main]`, so **every PR targeting a branch loses `build` and the
whole CodeQL tier**. Measured:

| PR | Checks that ran | Missing |
|---|---|---|
| #640 | 13 | — |
| #642 | **4** | `build`, CodeQL, `readiness` |
| #633 | 19 | — |
| #637 | 14 | CodeQL, `Analyze (swift)` |
| #575 | 7 | — |
| #576 | **2** | `build`, CodeQL |
| #616 | **4** | `build`, CodeQL |

So "all green" means thirteen checks on #640 and four on #642. Each gap closes by retargeting at `main`
once the parent lands — it is not a defect in the work, but it must not be read as equivalent coverage.

Separately, **#622's four required workflows read `action_required`** — created and never executed.
That conclusion appears only in `actions/runs`, not in `check-runs`, so a check-runs read makes #622
look green. The approval condition was measured over 200 runs as **per-head**, not per-branch and not
bot-versus-human, which means the final recut will arrive with its required workflows queued again.

**#637's acceptance suite is wired to nothing at all** — no workflow invokes `xcodebuild` or the
`MotionHost` scheme, and `verification.json` has no Sheet entry. That is not a branch-targeting gap; it
is a permanent absence of regression protection for the repair.

## 7. Missing reviews

No PR in the set carries a human GitHub review. Codex currency lives in the `updated_at` of the
`codex-review-state:v1` comment, which is **edited in place**, so a receipt's `created_at` is frozen at
its first run and reads stale while the head is in fact reviewed — the trap that previously made
#578/#579/#582 look unreviewed. Any currency claim in this programme has to read `updated_at`.

## 8. Deployment side effects

**Every push to `main` deploys kinetixui.com, and rollback is mostly unavailable.** That makes the
website set (77 files of homepage, footer and catalogue) the single highest-consequence integration in
the programme, and §8 requires a separate deployment impact review before any of it is integrated. None
was performed, nothing was merged, nothing was deployed.

The three `vercel.json` registries are the mechanism by which branches suppress their own previews; on
merge those branch names cease to exist and the entries become permanent dead weight. Merging the Sheet
stack alone adds six such entries.

3. **#559 gates #632.** #632 cannot land without #559, #559 brings an uncovered changeset, and the
   release machinery is fail-closed in both orderings. So the React SegmentedControl forced-colours
   repair is a release decision, not an accessibility one.
