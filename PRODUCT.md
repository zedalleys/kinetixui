## Product Purpose

KinetixUI provides shared design tokens and platform-specific component implementations. The website supports discovery, documentation and theme customization.

## Capabilities and Constraints

Existing Create is a theme workspace with real component previews and deterministic exports. The broader Create Studio roadmap is planned, not implemented by this visual refresh. Preserve library public APIs, export behavior, responsive layouts, RTL, accessibility and an 8px spacing foundation.

## Brand Commitments

Kinetic Weave v1, approved 2026-11-02, is a full-colour identity: Electric Indigo `#6054F4`, Soft Violet `#A78BFA`, Electric Cyan `#28C7D9`, Midnight Navy `#17233D`, Cloud White `#F6F7FC`, Deep Canvas `#0C1229`, with `#5143DB` as the accessible light-theme action colour. Identity colour and accessible interactive colour are deliberately separate roles.

The hero artwork is the owner-supplied low-poly triangulated mesh from `OH38WC1.svg`/JPG, recoloured in that palette and used at a scale that integrates it with the hero rather than boxing it. No Arabian fusion or motifs; the separate coloured OFFLINE_ABSTRACT_SHAPES reference is excluded. The K logo and the polygon are two different brand assets and neither substitutes for the other.

This supersedes the grayscale brand brief of 2026-11-01, which is retained only as a record in `docs/audits/polygon-refresh/`.
