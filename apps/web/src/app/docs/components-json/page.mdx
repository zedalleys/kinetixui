# components.json

`packages/ui/components.json` configures the shadcn CLI for the library itself.

```json
{
  "$schema": "https://ui.shadcn.com/schema.json",
  "style": "new-york",
  "rsc": false,
  "tsx": true,
  "tailwind": {
    "config": "tailwind.config.ts",
    "css": "../tokens/dist/web/globals.css",
    "baseColor": "slate",
    "cssVariables": true
  },
  "aliases": {
    "components": "@kinetixui/ui/components",
    "utils": "@kinetixui/ui/lib/utils",
    "ui": "@kinetixui/ui/components"
  },
  "registries": {
    "@kinetixui": "https://kinetixui.com/r/{name}.json"
  }
}
```

In a **consuming** app, point `tailwind.css` at wherever you imported the token
contract and set your own `aliases`.
