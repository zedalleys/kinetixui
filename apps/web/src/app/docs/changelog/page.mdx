# Changelog

## Unreleased

- **SwiftUI library** (`packages/ui-swiftui`) — the native iOS port,
  built the same way the Compose library was: `KinetixTheme` (the
  `@Environment(\.kinetixColors)` semantic set + a light/dark wrapper)
  plus **68 `Kinetix*` views — the full React component surface** bar
  three deliberate non-ports (`Form` — `KinetixField` is the equivalent;
  `NavigationMenu` — no touch idiom; `Combobox` — a recipe). Each mirrors
  its `packages/ui/src/components/*.tsx` counterpart 1:1: controls, the
  full input + field set, display primitives, data (Table / DataTable /
  Carousel), disclosure/navigation, the overlay & menu classes (Dialog,
  Sheet, Popover, Dropdown/Context menus, Command palette, Tooltip,
  Toaster), plus `KinetixChart` over the system `Charts` framework and
  `KinetixCalendar` over `DatePicker(.graphical)`. The token engine emits
  a SwiftUI-`Color` semantic set (`KinetixColorsSwiftUI` / `…Dark`, both
  passes, now including the `--chart-1…5` palette) alongside the untouched
  UIColor output — `UIColor` is UIKit-only and won't compile on macOS.
  Verified by `swift build` on `macos-latest` on every push. New
  [SwiftUI](/docs/swiftui) docs page. Standalone SwiftPM package, not on
  the registry.
- **Jetpack Compose library** (`packages/ui-compose`) — 69 native
  `Kinetix*` composables on the token contract, one per React component
  (`Chart`, `Form`, `NavigationMenu` documented as deliberate non-ports).
  New [Jetpack Compose](/docs/compose) docs page: `KinetixTheme` setup,
  the vendored-token flow, and the full known-gaps list. Compiled in CI
  on every push. Not on Maven yet.
- **CLI `list` + `add --all`** (`@kinetixui/cli@0.3.0`) — `npx @kinetixui/cli
  list` prints every component in the registry; `npx @kinetixui/cli add --all`
  installs all of them in one shot instead of naming each one. Backed by a
  new registry index manifest (`apps/web/public/r/registry.json`), generated
  alongside the per-component files.
- **`kinetixui` CLI** — a first-party install tool (`packages/cli`). `npx
  kinetixui init` sets up `kinetixui.json` (your aliases) and pulls in the
  token contract; `npx @kinetixui/cli add <name>` resolves registry dependencies,
  installs the npm packages a component needs with whichever package manager
  your project already uses, and writes the source into your configured
  directory. Every doc page's install snippet now reads `npx @kinetixui/cli add
  <name>` — no other tool's CLI required.
- **6 more components** — web-pattern gap fill, all on the existing token
  contract: **`CodeBlock`** (copy button, optional file tabs), **`Metric`**
  (stat/KPI display — label, value, trend indicator, optional chart slot),
  **`NumberInput`** (increment/decrement numeric field), **`Quote`**
  (blockquote with attributed author), **`Footer`** / `FooterColumn` /
  `FooterLink` / `FooterBottom` (page footer shell), **`TableOfContents`**
  (anchor-link nav with active-item state). **72-item registry.**
- **9 more components** — mobile-pattern gap fill, all on the existing token
  contract: **`Rating`** (star input/display), **`Spinner`** (loading
  indicator), **`List`** / **`ListItem`** (leading icon/avatar, title,
  description, trailing content), **`Stepper`** (horizontal/vertical numbered
  progress), **`Fab`** (floating action button, circular or extended),
  **`TabBar`** / **`TabBarItem`** (mobile bottom navigation),
  **`NavigationBar`** (mobile top app bar), **`FileUpload`** /
  **`FileUploadItem`** (drag-and-drop zone + file list), **`AvatarGroup`**
  (stacked avatars with overflow). **`DatePicker`** promoted from a
  Popover+Calendar recipe to a real component (label / helper text / error
  states). **66-item registry.**
- **4 more components** — **`AudioPlayer`** (`variant="full" | "mini"` —
  native `<audio>` with a scrubber, `mm:ss` labels, ±10s skip, prev/next),
  **`CircularProgress`** (ring with optional centre value), **`Image`**
  (ratio presets 1:1 / 3:2 / 4:3 / 3:4 / 3:1 / 16:9, muted loading
  placeholder, error fallback), **`Inform`** (persistent dismissible
  intent-tinted notice with an optional CTA — information / warning /
  success / error / action). **57-item registry.**
- **Native text styles** — typography composites now also compile to
  `KinetixType.swift` (SwiftUI), `KinetixType.kt` (Compose `TextStyle`) and
  `app_text.dart` (Flutter `TextStyle`), and land in `tokens.ts` as a `text.*`
  object. Web + all 3 mobile platforms now carry the full type scale.
- **Elevation tokens** (new category) — `--shadow-sm/md/lg/xl`
  plus `--shadow-focus` / `-destructive` / `-success` / `-warning` (the focus ring
  as a crisp edge + soft colour glow). Wired into the Tailwind preset (`shadow-*`,
  `shadow-focus*`); Input / Textarea / Select now use `shadow-focus`.
- **Typography build** — `tokens/semantic/typography.json` now compiles: an
  `extras.css` with `--text-<style>` shorthands, and a `text-<style>` Tailwind
  scale carrying line-height / tracking / weight (`text-body-md`, `text-headline-lg`…).
- **`Field`** — label + control + description + feedback composition;
  `FieldMessage` intents `error | warning | success | info` each with an icon,
  label & message colour track the invalid state.
- **`InputGroup`** + `InputGroupInput` / `InputGroupAddon` / `InputGroupText` /
  `InputGroupButton` — the design source's Fixed Add-on pattern (prefix/suffix
  icon, text, dropdown, button in one bordered shell). Plus **`PasswordInput`**
  recipe (show/hide toggle).
- **`--info`** semantic colour + `success` / `info` container roles; wired into
  `Alert` (`variant="info"`) and `FieldMessage`.
- **`corners`** prop on `Input` (`sharp | default | rounded | pill`) and `Button`
  (`sharp | default | pill`); `Button` / `Input` / `Textarea` / `Select` focus
  now uses `--shadow-focus` throughout.
- 57-item registry.

- **Components — full component parity.** 15 more shipped: Calendar, Carousel,
  Chart, Combobox, Command, Context Menu, Data Table, Date Picker, Drawer, Form,
  Input OTP, Menubar, Navigation Menu, Resizable, Sidebar. **47 components**;
  **48-item registry**. New deps: recharts, react-day-picker, embla, vaul, cmdk,
  react-hook-form + zod, input-otp, @tanstack/react-table, react-resizable-panels.
- Earlier in this cycle: 31 components ported (Accordion … Tooltip), web CSS as
  **HSL channels** (opacity modifiers), `--chart-1…5` and `--sidebar-*` tokens
  (+ `caret-blink` animation).
- **Site** — every component doc route present; ⌘K over all of them; all static.
- **Deploy** — `pnpm build:web` passes; `vercel.json` + `DEPLOY.md` (Vercel +
  GoDaddy DNS).
