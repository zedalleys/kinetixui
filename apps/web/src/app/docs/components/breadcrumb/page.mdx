## React installation

Install the package the usage below imports from:

```bash
npm i @kinetixui/ui @kinetixui/tokens
```

The project also needs Tailwind CSS 3 and the KinetixUI preset; see [Installation](/docs/installation). To own
the source instead, copy it into your project with the CLI and import from the folder it writes to:

```bash
npx @kinetixui/cli add breadcrumb
```

## React usage

```tsx
import { Breadcrumb, BreadcrumbList, BreadcrumbItem, BreadcrumbLink, BreadcrumbPage, BreadcrumbSeparator } from "@kinetixui/ui";
```

Styled from the KinetixUI token contract, in light and dark, with no extra configuration. See
[Accessibility](/docs/accessibility) for how the React library is tested.
