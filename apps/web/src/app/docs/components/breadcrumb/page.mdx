# Breadcrumb

Displays the path to the current resource using a hierarchy of links.

<ComponentPreview name="breadcrumb-demo" />

## Installation

```bash
npx @kinetixui/cli add breadcrumb
```

## Usage

```tsx
import { Breadcrumb, BreadcrumbList, BreadcrumbItem, BreadcrumbLink, BreadcrumbPage, BreadcrumbSeparator } from "@kinetixui/ui";
```

Styled entirely from the KinetixUI token contract — `bg-primary`,
`text-muted-foreground`, `border-input`, `ring-ring`. Works in light and dark
with no extra config.
