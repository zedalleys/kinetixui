# Kanban Board

<ComponentMeta />

Draggable cards across columns with keyboard DnD, built on @dnd-kit's multiple-containers sortable pattern.

<ComponentPreview name="kanban-board-demo" />

## Installation

```bash
npx @kinetixui/cli add kanban-board
```

## Usage

```tsx
import { KanbanBoard } from "@kinetixui/ui";
```

Styled entirely from the KinetixUI token contract — `bg-primary`,
`text-muted-foreground`, `border-input`, `ring-ring`. Works in light and dark
with no extra config, and keyboard + ARIA behaviour comes from Radix — see
[Accessibility](/docs/accessibility).
