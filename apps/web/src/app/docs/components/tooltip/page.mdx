# Tooltip

A popup that displays information related to an element on focus / hover.

<ComponentPreview name="tooltip-demo" />

## Installation

```bash
npx @kinetixui/cli add tooltip
```

## Usage

```tsx
import { Tooltip, TooltipProvider, TooltipTrigger, TooltipContent } from "@kinetixui/ui";
```

Styled entirely from the KinetixUI token contract — `bg-primary`,
`text-muted-foreground`, `border-input`, `ring-ring`. Works in light and dark
with no extra config.
