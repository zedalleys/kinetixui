# Badge

Displays a badge or a component that looks like a badge. Design source node 54855:13995.

<ComponentPreview name="badge-demo" />

## Installation

```bash
npx shadcn@latest add https://kinetixui.com/r/badge.json
```

## Usage

```tsx
import { Badge } from "@kinetixui/ui";
```

Styled entirely from the KinetixUI token contract — `bg-primary`,
`text-muted-foreground`, `border-input`, `ring-ring`. Works in light and dark
with no extra config.
