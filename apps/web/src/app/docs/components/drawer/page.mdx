# Drawer

A drawer component for React, built on Vaul.

<ComponentPreview name="drawer-demo" />

## Installation

```bash
npx shadcn@latest add https://kinetixui.com/r/drawer.json
```

## Usage

```tsx
import { Drawer, DrawerTrigger, DrawerContent, DrawerHeader, DrawerTitle, DrawerFooter } from "@kinetixui/ui";
```

Styled entirely from the KinetixUI token contract — `bg-primary`,
`text-muted-foreground`, `border-input`, `ring-ring`. Works in light and dark
with no extra config.
