## Quantities

NumberInput is the quantity picker: a cart line, a ticket count, a number of nights. There is no separate
QuantityPicker. For several counts chosen together, use [GuestPicker](/docs/components/guest-picker), which is built
from NumberInputs.

```tsx
<NumberInput
  aria-label="Quantity"
  min={1}
  max={10}
  value={qty}
  onChange={setQty}
  decrementLabel="Remove one"
  incrementLabel="Add one"
  formatAnnouncement={(n) => `${n} in cart`}
/>
```

- The stepper buttons are named "Decrease" and "Increase" by default; `decrementLabel` and `incrementLabel` localise
  them or make them specific.
- At `min` or `max` the button stays focusable and is marked `aria-disabled`, so a keyboard user pressing it
  repeatedly does not lose focus.
- A change made with the steppers is announced in a polite live region (`formatAnnouncement`); typing is not
  announced, because the reader already hears what they type.

Styled entirely from the KinetixUI token contract — `bg-action`,
`text-muted-foreground`, `border-input`, `ring-ring`. Works in light and dark
with no extra config. Keyboard and ARIA behaviour is inherited from Radix where the
component is built on a primitive; the hand-built widgets (DataGrid, TreeView,
ColorPicker, MultiSelect, Tour, KanbanBoard) have their own documented interaction
models — see [Accessibility](/docs/accessibility).
