# Number Input

A numeric field with increment / decrement controls.

<ComponentPreview name="number-input-demo" />

## Installation

```bash
npx shadcn@latest add https://kinetixui.com/r/number-input.json
```

## Usage

```tsx
import { NumberInput } from "@kinetixui/ui";
```

Styled entirely from the KinetixUI token contract — `bg-primary`,
`text-muted-foreground`, `border-input`, `ring-ring`. Works in light and dark
with no extra config.
