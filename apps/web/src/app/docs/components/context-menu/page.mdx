# Context Menu

Displays a menu located at the pointer, triggered by a right click.

<ComponentPreview name="context-menu-demo" />

## Installation

```bash
npx kinetixui add context-menu
```

## Usage

```tsx
import { ContextMenu, ContextMenuTrigger, ContextMenuContent, ContextMenuItem, ContextMenuSeparator } from "@kinetixui/ui";
```

Styled entirely from the KinetixUI token contract — `bg-primary`,
`text-muted-foreground`, `border-input`, `ring-ring`. Works in light and dark
with no extra config.
