# App Bar

<ComponentMeta />

A web application top bar — brand, primary nav links and trailing actions in a sticky header; the nav collapses behind a menu toggle on small screens.

<ComponentPreview name="app-bar-demo" />

## Installation

```bash
npx @kinetixui/cli add app-bar
```

## Usage

```tsx
import { AppBar, AppBarBrand, AppBarNav, AppBarLink, AppBarActions } from "@kinetixui/ui";
```

Styled entirely from the KinetixUI token contract — `bg-primary`,
`text-muted-foreground`, `border-input`, `ring-ring`. Works in light and dark
with no extra config, and keyboard + ARIA behaviour comes from Radix — see
[Accessibility](/docs/accessibility).
