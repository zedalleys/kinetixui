# Pagination

Pagination with page navigation, next and previous links.

<ComponentPreview name="pagination-demo" />

## Installation

```bash
npx @kinetixui/cli add pagination
```

## Usage

```tsx
import { Pagination, PaginationContent, PaginationItem, PaginationLink, PaginationPrevious, PaginationNext, PaginationEllipsis } from "@kinetixui/ui";
```

Styled entirely from the KinetixUI token contract — `bg-primary`,
`text-muted-foreground`, `border-input`, `ring-ring`. Works in light and dark
with no extra config.
