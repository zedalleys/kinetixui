# Table Of Contents

An anchor-link nav list with indent levels and an active-item state.

<ComponentPreview name="table-of-contents-demo" />

## Installation

```bash
npx kinetixui add table-of-contents
```

## Usage

```tsx
import { TableOfContents } from "@kinetixui/ui";
```

Styled entirely from the KinetixUI token contract — `bg-primary`,
`text-muted-foreground`, `border-input`, `ring-ring`. Works in light and dark
with no extra config.
