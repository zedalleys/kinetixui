## React usage

```tsx
import { SegmentedControl, SegmentedControlItem } from "@kinetixui/ui";
```

Styled entirely from the KinetixUI token contract — `bg-action`,
`text-muted-foreground`, `border-input`, `ring-ring`. Works in light and dark
with no extra config.

The strip is a `radiogroup` of `radio`s, and it always has exactly one chosen
segment: activating the segment that is already chosen is a no-op, and
`onValueChange` is never called with `""`. A consumer that genuinely wants
nothing chosen can still pass `value=""` itself.

## Keyboard

Selection follows focus, as it does in any radiogroup: an arrow key moves focus
to the next segment **and** chooses it, so `onValueChange` fires on an arrow
press rather than waiting for Enter. Home and End move to the first and last
segment the same way, the arrows follow the reading direction, and a disabled
segment is stepped over rather than chosen. The strip is one tab stop, and
tabbing into it lands on the segment already chosen, which changes nothing.
