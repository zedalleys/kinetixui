# Switch

A control that allows the user to toggle between checked and not checked. Reconciled 1:1 with design source node 54855:13984.

<ComponentPreview name="switch-demo" />

## Installation

```bash
npx @kinetixui/cli add switch
```

## Usage

```tsx
import { Switch } from "@kinetixui/ui";
```

Styled entirely from the KinetixUI token contract — `bg-primary`,
`text-muted-foreground`, `border-input`, `ring-ring`. Works in light and dark
with no extra config, and keyboard + ARIA behaviour comes from Radix — see
[Accessibility](/docs/accessibility).
