# Table

A responsive table component.

<ComponentPreview name="table-demo" />

## Installation

```bash
npx kinetixui add table
```

## Usage

```tsx
import { Table, TableHeader, TableBody, TableRow, TableHead, TableCell, TableCaption } from "@kinetixui/ui";
```

Styled entirely from the KinetixUI token contract — `bg-primary`,
`text-muted-foreground`, `border-input`, `ring-ring`. Works in light and dark
with no extra config.
