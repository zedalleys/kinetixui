# Input Group

<ComponentMeta />

A bordered shell hosting an input plus fixed add-ons (icon, text, dropdown, button) on either side — the design source's Fixed Add-on pattern. Border, focus glow and invalid state apply to the whole group.

<ComponentPreview name="input-group-demo" />

## Installation

```bash
npx @kinetixui/cli add input-group
```

## Usage

```tsx
import { InputGroup, InputGroupInput, InputGroupAddon, InputGroupText, InputGroupButton } from "@kinetixui/ui";
```

Styled entirely from the KinetixUI token contract — `bg-primary`,
`text-muted-foreground`, `border-input`, `ring-ring`. Works in light and dark
with no extra config, and keyboard + ARIA behaviour comes from Radix — see
[Accessibility](/docs/accessibility).
