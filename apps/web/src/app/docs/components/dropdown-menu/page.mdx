# Dropdown Menu

Displays a menu to the user — such as a set of actions or functions — triggered by a button.

<ComponentPreview name="dropdown-menu-demo" />

## Installation

```bash
npx @kinetixui/cli add dropdown-menu
```

## Usage

```tsx
import { DropdownMenu, DropdownMenuTrigger, DropdownMenuContent, DropdownMenuItem, DropdownMenuLabel, DropdownMenuSeparator } from "@kinetixui/ui";
```

Styled entirely from the KinetixUI token contract — `bg-primary`,
`text-muted-foreground`, `border-input`, `ring-ring`. Works in light and dark
with no extra config, and keyboard + ARIA behaviour comes from Radix — see
[Accessibility](/docs/accessibility).
