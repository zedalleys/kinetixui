## React installation

Install the package the usage below imports from:

<Command op="install-react" />

The project also needs Tailwind CSS 3 and the KinetixUI preset; see [Installation](/docs/installation). To own
the source instead, copy it into your project with the CLI and import from the folder it writes to:

<Command op="cli-add" components={["select"]} />

## React usage

```tsx
import { Select, SelectTrigger, SelectValue, SelectContent, SelectItem } from "@kinetixui/ui";
```

Styled from the KinetixUI token contract, in light and dark, with no extra configuration. Keyboard and
ARIA behaviour comes from Radix Select; see [Accessibility](/docs/accessibility).
