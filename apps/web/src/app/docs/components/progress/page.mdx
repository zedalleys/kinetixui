# Progress

Displays an indicator showing the completion progress of a task.

## React installation

<Command op="cli-add" components={["progress"]} />

## React usage

```tsx
import { Progress } from "@kinetixui/ui";
```

`value` and `max` are in the same units. The fill grows from inline start,
including in RTL. The progressbar exposes the current value as soon as it changes.
Set `value={null}` when the amount is unknown. The fill clears and the progressbar
omits its current value.

The fill transitions over the `base` duration with `standard` easing and
retargets when a new value arrives. With reduced motion the fill updates immediately.
Progress is read-only and adds no keyboard stop.
