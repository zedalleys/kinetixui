# File Upload

A drag-and-drop zone plus file list, single or multiple.

<ComponentPreview name="file-upload-demo" />

## Installation

```bash
npx shadcn@latest add https://kinetixui.com/r/file-upload.json
```

## Usage

```tsx
import { FileUpload, FileUploadItem } from "@kinetixui/ui";
```

Styled entirely from the KinetixUI token contract — `bg-primary`,
`text-muted-foreground`, `border-input`, `ring-ring`. Works in light and dark
with no extra config.
