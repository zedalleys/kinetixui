# Tabs

A set of layered sections of content — known as tab panels — displayed one at a time.

<ComponentPreview name="tabs-demo" />

## Installation

```bash
npx kinetixui add tabs
```

## Usage

```tsx
import { Tabs, TabsList, TabsTrigger, TabsContent } from "@kinetixui/ui";
```

Styled entirely from the KinetixUI token contract — `bg-primary`,
`text-muted-foreground`, `border-input`, `ring-ring`. Works in light and dark
with no extra config.
