# Circular Progress

A ring progress indicator with an optional centre value.

<ComponentPreview name="circular-progress-demo" />

## Installation

```bash
npx shadcn@latest add https://kinetixui.com/r/circular-progress.json
```

## Usage

```tsx
import { CircularProgress } from "@kinetixui/ui";
```

Styled entirely from the KinetixUI token contract — `bg-primary`,
`text-muted-foreground`, `border-input`, `ring-ring`. Works in light and dark
with no extra config.
