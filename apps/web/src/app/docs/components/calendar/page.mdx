# Calendar

A date field component built on react-day-picker.

<ComponentPreview name="calendar-demo" />

## Installation

```bash
npx kinetixui add calendar
```

## Usage

```tsx
import { Calendar } from "@kinetixui/ui";
```

Styled entirely from the KinetixUI token contract — `bg-primary`,
`text-muted-foreground`, `border-input`, `ring-ring`. Works in light and dark
with no extra config.
