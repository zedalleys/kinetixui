# Command

<ComponentMeta />

Fast, composable, unstyled command menu for React (cmdk).

<ComponentPreview name="command-demo" />

## Installation

```bash
npx @kinetixui/cli add command
```

## Usage

```tsx
import { Command, CommandInput, CommandList, CommandEmpty, CommandGroup, CommandItem, CommandDialog } from "@kinetixui/ui";
```

Styled entirely from the KinetixUI token contract — `bg-primary`,
`text-muted-foreground`, `border-input`, `ring-ring`. Works in light and dark
with no extra config, and keyboard + ARIA behaviour comes from Radix — see
[Accessibility](/docs/accessibility).
