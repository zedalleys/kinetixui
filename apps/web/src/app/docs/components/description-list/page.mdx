# Description List

<ComponentMeta />

`<dl>` term/detail rows with a spec-sheet skin — a `row` or `stacked` layout, each row with its own divider.

<ComponentPreview name="description-list-demo" />

## Installation

```bash
npx @kinetixui/cli add description-list
```

## Usage

```tsx
import { DescriptionList, DescriptionListItem } from "@kinetixui/ui";
```

Styled entirely from the KinetixUI token contract — `bg-primary`,
`text-muted-foreground`, `border-input`, `ring-ring`. Works in light and dark
with no extra config, and keyboard + ARIA behaviour comes from Radix — see
[Accessibility](/docs/accessibility).
