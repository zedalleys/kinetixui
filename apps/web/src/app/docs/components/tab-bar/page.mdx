# Tab Bar

A mobile bottom navigation bar.

<ComponentPreview name="tab-bar-demo" />

## Installation

```bash
npx @kinetixui/cli add tab-bar
```

## Usage

```tsx
import { TabBar, TabBarItem } from "@kinetixui/ui";
```

Styled entirely from the KinetixUI token contract — `bg-primary`,
`text-muted-foreground`, `border-input`, `ring-ring`. Works in light and dark
with no extra config.
