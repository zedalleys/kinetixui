# Input Otp

Accessible one-time-password input with copy-paste.

<ComponentPreview name="input-otp-demo" />

## Installation

```bash
npx @kinetixui/cli add input-otp
```

## Usage

```tsx
import { InputOTP, InputOTPGroup, InputOTPSlot, InputOTPSeparator } from "@kinetixui/ui";
```

Styled entirely from the KinetixUI token contract — `bg-primary`,
`text-muted-foreground`, `border-input`, `ring-ring`. Works in light and dark
with no extra config.
