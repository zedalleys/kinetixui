# Scroll Area

Augments native scroll functionality for custom, cross-browser styling.

<ComponentPreview name="scroll-area-demo" />

## Installation

```bash
npx kinetixui add scroll-area
```

## Usage

```tsx
import { ScrollArea, ScrollBar } from "@kinetixui/ui";
```

Styled entirely from the KinetixUI token contract — `bg-primary`,
`text-muted-foreground`, `border-input`, `ring-ring`. Works in light and dark
with no extra config.
