## React installation

Install the package the usage below imports from:

```bash
npm i @kinetixui/ui @kinetixui/tokens
```

The project also needs Tailwind CSS 3 and the KinetixUI preset; see [Installation](/docs/installation). To own
the source instead, copy it into your project with the CLI and import from the folder it writes to:

```bash
npx @kinetixui/cli add input
```

## React usage

```tsx
import { Input } from "@kinetixui/ui";

<Input type="email" placeholder="you@example.com" />
```

## States

<ComponentPreview name="input-states" />

`Focus` is `:focus-visible` and `Disabled` is the native attribute. Setting
`state="Error"` also sets `aria-invalid`. Label and helper text are not part of
the control — they belong to the [`Field`](/docs/components/field) composition.
