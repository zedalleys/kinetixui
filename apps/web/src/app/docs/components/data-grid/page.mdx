# Data Grid

<ComponentMeta />

Row-virtualized grid with column resize, drag-to-reorder, left/right pin, sort, and double-click-to-edit cells.

<ComponentPreview name="data-grid-demo" />

## Installation

```bash
npx @kinetixui/cli add data-grid
```

## Usage

```tsx
import { DataGrid } from "@kinetixui/ui";
```

Styled entirely from the KinetixUI token contract — `bg-primary`,
`text-muted-foreground`, `border-input`, `ring-ring`. Works in light and dark
with no extra config, and keyboard + ARIA behaviour comes from Radix — see
[Accessibility](/docs/accessibility).
