# Hover Card

For sighted users to preview content available behind a link.

<ComponentPreview name="hover-card-demo" />

## Installation

```bash
npx shadcn@latest add https://kinetixui.com/r/hover-card.json
```

## Usage

```tsx
import { HoverCard, HoverCardTrigger, HoverCardContent } from "@kinetixui/ui";
```

Styled entirely from the KinetixUI token contract — `bg-primary`,
`text-muted-foreground`, `border-input`, `ring-ring`. Works in light and dark
with no extra config.
