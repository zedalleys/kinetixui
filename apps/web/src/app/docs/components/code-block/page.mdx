# Code Block

A code display with a copy button and, for more than one file, a tab strip.

<ComponentPreview name="code-block-demo" />

## Installation

```bash
npx @kinetixui/cli add code-block
```

## Usage

```tsx
import { CodeBlock } from "@kinetixui/ui";
```

Styled entirely from the KinetixUI token contract — `bg-primary`,
`text-muted-foreground`, `border-input`, `ring-ring`. Works in light and dark
with no extra config.
