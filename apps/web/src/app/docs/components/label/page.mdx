# Label

Renders an accessible label associated with controls.

<ComponentPreview name="label-demo" />

## Installation

```bash
npx shadcn@latest add https://kinetixui.com/r/label.json
```

## Usage

```tsx
import { Label } from "@kinetixui/ui";
```

Styled entirely from the KinetixUI token contract — `bg-primary`,
`text-muted-foreground`, `border-input`, `ring-ring`. Works in light and dark
with no extra config.
