# Password Input

An InputGroup recipe — a password field with a show / hide toggle.

<ComponentPreview name="password-input-demo" />

## Installation

```bash
npx shadcn@latest add https://kinetixui.com/r/password-input.json
```

## Usage

```tsx
import { PasswordInput } from "@kinetixui/ui";
```

Styled entirely from the KinetixUI token contract — `bg-primary`,
`text-muted-foreground`, `border-input`, `ring-ring`. Works in light and dark
with no extra config.
