# Carousel

<ComponentMeta />

A carousel with motion and swipe, built on Embla.

<ComponentPreview name="carousel-demo" />

## Installation

```bash
npx @kinetixui/cli add carousel
```

## Usage

```tsx
import { Carousel, CarouselContent, CarouselItem, CarouselPrevious, CarouselNext } from "@kinetixui/ui";
```

Styled entirely from the KinetixUI token contract — `bg-primary`,
`text-muted-foreground`, `border-input`, `ring-ring`. Works in light and dark
with no extra config, and keyboard + ARIA behaviour comes from Radix — see
[Accessibility](/docs/accessibility).
