# Button Group

<ComponentMeta />

Visually joins a row or column of buttons into a connected, segmented-control-style cluster.

<ComponentPreview name="button-group-demo" />

## Installation

```bash
npx @kinetixui/cli add button-group
```

## Usage

```tsx
import { ButtonGroup, ButtonGroupSeparator, ButtonGroupText } from "@kinetixui/ui";
```

Styled entirely from the KinetixUI token contract — `bg-primary`,
`text-muted-foreground`, `border-input`, `ring-ring`. Works in light and dark
with no extra config, and keyboard + ARIA behaviour comes from Radix — see
[Accessibility](/docs/accessibility).
