# Marquee

<ComponentMeta />

An auto-scrolling horizontal ticker (logo strip, testimonials), pausing on hover and respecting prefers-reduced-motion.

<ComponentPreview name="marquee-demo" />

## Installation

```bash
npx @kinetixui/cli add marquee
```

## Usage

```tsx
import { Marquee } from "@kinetixui/ui";
```

Styled entirely from the KinetixUI token contract — `bg-primary`,
`text-muted-foreground`, `border-input`, `ring-ring`. Works in light and dark
with no extra config, and keyboard + ARIA behaviour comes from Radix — see
[Accessibility](/docs/accessibility).
