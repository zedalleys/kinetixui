# Popover

Displays rich content in a portal, triggered by a button.

<ComponentPreview name="popover-demo" />

## Installation

```bash
npx kinetixui add popover
```

## Usage

```tsx
import { Popover, PopoverTrigger, PopoverContent } from "@kinetixui/ui";
```

Styled entirely from the KinetixUI token contract — `bg-primary`,
`text-muted-foreground`, `border-input`, `ring-ring`. Works in light and dark
with no extra config.
