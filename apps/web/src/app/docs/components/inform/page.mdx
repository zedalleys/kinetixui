# Inform

A persistent, dismissible, intent-tinted inline notice with an optional action (variant: information | warning | success | error | action).

<ComponentPreview name="inform-demo" />

## Installation

```bash
npx @kinetixui/cli add inform
```

## Usage

```tsx
import { Inform, informVariants } from "@kinetixui/ui";
```

Styled entirely from the KinetixUI token contract — `bg-primary`,
`text-muted-foreground`, `border-input`, `ring-ring`. Works in light and dark
with no extra config, and keyboard + ARIA behaviour comes from Radix — see
[Accessibility](/docs/accessibility).
