# Inform

A persistent, dismissible, intent-tinted inline notice with an optional action. Ported 1:1 from design source — Capi "Inform" (variant: information | warning | success | error | action).

<ComponentPreview name="inform-demo" />

## Installation

```bash
npx shadcn@latest add https://kinetixui.com/r/inform.json
```

## Usage

```tsx
import { Inform, informVariants } from "@kinetixui/ui";
```

Styled entirely from the KinetixUI token contract — `bg-primary`,
`text-muted-foreground`, `border-input`, `ring-ring`. Works in light and dark
with no extra config.
