# Form

Building forms with React Hook Form and Zod.

<ComponentPreview name="form-demo" />

## Installation

```bash
npx shadcn@latest add https://kinetixui.com/r/form.json
```

## Usage

```tsx
import { Form, FormField, FormItem, FormLabel, FormControl, FormDescription, FormMessage } from "@kinetixui/ui";
```

Styled entirely from the KinetixUI token contract — `bg-primary`,
`text-muted-foreground`, `border-input`, `ring-ring`. Works in light and dark
with no extra config.
