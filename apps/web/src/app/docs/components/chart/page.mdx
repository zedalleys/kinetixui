# Chart

Charts built on Recharts, themed with `--chart-1…5`.

<ComponentPreview name="chart-demo" />

## Installation

```bash
npx @kinetixui/cli add chart
```

## Usage

```tsx
import { ChartContainer, ChartTooltip, ChartTooltipContent, ChartLegend, ChartLegendContent } from "@kinetixui/ui";
```

Styled entirely from the KinetixUI token contract — `bg-primary`,
`text-muted-foreground`, `border-input`, `ring-ring`. Works in light and dark
with no extra config, and keyboard + ARIA behaviour comes from Radix — see
[Accessibility](/docs/accessibility).
