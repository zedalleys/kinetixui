# Empty

<ComponentMeta />

A placeholder for a zero-results state — an empty table, an empty search, a fresh workspace.

<ComponentPreview name="empty-demo" />

## Installation

```bash
npx @kinetixui/cli add empty
```

## Usage

```tsx
import { Empty, EmptyHeader, EmptyMedia, EmptyTitle, EmptyDescription, EmptyContent } from "@kinetixui/ui";
```

Styled entirely from the KinetixUI token contract — `bg-primary`,
`text-muted-foreground`, `border-input`, `ring-ring`. Works in light and dark
with no extra config, and keyboard + ARIA behaviour comes from Radix — see
[Accessibility](/docs/accessibility).
