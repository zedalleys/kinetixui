# Sidebar

A composable, themeable and customizable sidebar — uses `--sidebar-*` tokens.

<ComponentPreview name="sidebar-demo" />

## Installation

```bash
npx kinetixui add sidebar
```

## Usage

```tsx
import { SidebarProvider, Sidebar, SidebarHeader, SidebarContent, SidebarGroup, SidebarMenu, SidebarMenuItem, SidebarMenuButton, SidebarTrigger, SidebarInset } from "@kinetixui/ui";
```

Styled entirely from the KinetixUI token contract — `bg-primary`,
`text-muted-foreground`, `border-input`, `ring-ring`. Works in light and dark
with no extra config.
