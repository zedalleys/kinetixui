# Tree View

<ComponentMeta />

Nested expand/collapse rows with keyboard roving tabindex and optional checkboxes.

<ComponentPreview name="tree-view-demo" />

## Installation

```bash
npx @kinetixui/cli add tree-view
```

## Usage

```tsx
import { TreeView, TreeItem } from "@kinetixui/ui";
```

Styled entirely from the KinetixUI token contract — `bg-primary`,
`text-muted-foreground`, `border-input`, `ring-ring`. Works in light and dark
with no extra config, and keyboard + ARIA behaviour comes from Radix — see
[Accessibility](/docs/accessibility).
