# Button

Trigger an action or event. Generated 1:1 from Figma `Personal Design System` ›
UI Components › 02. Controls &amp; Actions › Button (`54863:351`).

<ComponentPreview name="button-demo" />

## Installation

```bash
npx shadcn@latest add https://strata.design/r/button.json
```

## Usage

```tsx
import { Button } from "@strata/ui";

<Button variant="Primary" size="md">Save</Button>
<Button asChild variant="Link"><a href="/docs">Docs</a></Button>
```

## Variants

<ComponentPreview name="button-variants" />

`variant` and `size` map 1:1 to the Figma component properties. `Hover`,
`Focus`, and `Active` are CSS pseudo-classes; the `state` prop force-pins one
for snapshots and this documentation.

## API

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"Primary" \| "Secondary" \| "Outline" \| "Destructive" \| "Ghost" \| "Link"` | `"Primary"` |
| `size` | `"sm" \| "md" \| "lg" \| "icon"` | `"md"` |
| `state` | `"Default" \| "Hover" \| "Focus" \| "Active" \| "Disabled"` | `"Default"` |
| `asChild` | `boolean` | `false` |

Plus all native `<button>` attributes.
