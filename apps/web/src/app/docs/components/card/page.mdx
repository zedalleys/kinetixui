# Card

Displays a card with header, content, and footer.

<ComponentPreview name="card-demo" />

## Installation

```bash
npx kinetixui add card
```

## Usage

```tsx
import { Card, CardHeader, CardTitle, CardDescription, CardContent, CardFooter } from "@kinetixui/ui";
```

Styled entirely from the KinetixUI token contract — `bg-primary`,
`text-muted-foreground`, `border-input`, `ring-ring`. Works in light and dark
with no extra config.
