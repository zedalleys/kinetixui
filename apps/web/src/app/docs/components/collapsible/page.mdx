# Collapsible

An interactive component which expands / collapses a panel.

<ComponentPreview name="collapsible-demo" />

## Installation

```bash
npx shadcn@latest add https://kinetixui.com/r/collapsible.json
```

## Usage

```tsx
import { Collapsible, CollapsibleTrigger, CollapsibleContent } from "@kinetixui/ui";
```

Styled entirely from the KinetixUI token contract — `bg-primary`,
`text-muted-foreground`, `border-input`, `ring-ring`. Works in light and dark
with no extra config.
