# Resizable

Accessible resizable panel groups and layouts.

<ComponentPreview name="resizable-demo" />

## Installation

```bash
npx shadcn@latest add https://kinetixui.com/r/resizable.json
```

## Usage

```tsx
import { ResizablePanelGroup, ResizablePanel, ResizableHandle } from "@kinetixui/ui";
```

Styled entirely from the KinetixUI token contract — `bg-primary`,
`text-muted-foreground`, `border-input`, `ring-ring`. Works in light and dark
with no extra config.
