# Audio Player

Native `<audio>` playback with a scrubber, time labels and transport controls. `variant="full" | "mini"`.

<ComponentPreview name="audio-player-demo" />

## Installation

```bash
npx shadcn@latest add https://kinetixui.com/r/audio-player.json
```

## Usage

```tsx
import { AudioPlayer } from "@kinetixui/ui";
```

Styled entirely from the KinetixUI token contract — `bg-primary`,
`text-muted-foreground`, `border-input`, `ring-ring`. Works in light and dark
with no extra config.
