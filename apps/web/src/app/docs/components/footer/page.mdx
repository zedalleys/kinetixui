# Footer

A page footer shell — columns of nav links plus a bottom bar.

<ComponentPreview name="footer-demo" />

## Installation

```bash
npx shadcn@latest add https://kinetixui.com/r/footer.json
```

## Usage

```tsx
import { Footer, FooterColumn, FooterLink, FooterBottom } from "@kinetixui/ui";
```

Styled entirely from the KinetixUI token contract — `bg-primary`,
`text-muted-foreground`, `border-input`, `ring-ring`. Works in light and dark
with no extra config.
