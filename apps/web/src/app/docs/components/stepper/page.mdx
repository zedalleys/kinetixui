# Stepper

A numbered multi-step progress indicator, horizontal or vertical.

<ComponentPreview name="stepper-demo" />

## Installation

```bash
npx shadcn@latest add https://kinetixui.com/r/stepper.json
```

## Usage

```tsx
import { Stepper } from "@kinetixui/ui";
```

Styled entirely from the KinetixUI token contract — `bg-primary`,
`text-muted-foreground`, `border-input`, `ring-ring`. Works in light and dark
with no extra config.
