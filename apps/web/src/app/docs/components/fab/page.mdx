## Speed dial

A Fab that opens a short list of related actions. It is an example composed from `Fab`, a list of buttons and an
SVG filter, not a separate component: copy it from the Code tab and change the actions.

<ComponentPreview name="fab-speed-dial" />

The Fab carries `aria-expanded` and controls the list. Each action is a button named by its visible label, and Tab
moves from the Fab outward through them. Escape, a click outside or choosing an action closes the list and puts
focus back on the Fab. The motion uses the motion tokens and animates only transform and opacity; with reduced
motion the list opens and closes without moving.

## React installation

```bash
npx @kinetixui/cli add fab
```

## React usage

```tsx
import { Fab, fabVariants } from "@kinetixui/ui";
```

Styled entirely from the KinetixUI token contract — `bg-action`,
`text-muted-foreground`, `border-input`, `ring-ring`. Works in light and dark
with no extra config. Keyboard and ARIA behaviour is inherited from Radix where the
component is built on a primitive; the hand-built widgets (DataGrid, TreeView,
ColorPicker, MultiSelect, Tour, KanbanBoard) have their own documented interaction
models — see [Accessibility](/docs/accessibility).
