# Fab

A floating action button — circular or extended.

<ComponentPreview name="fab-demo" />

## Installation

```bash
npx shadcn@latest add https://kinetixui.com/r/fab.json
```

## Usage

```tsx
import { Fab, fabVariants } from "@kinetixui/ui";
```

Styled entirely from the KinetixUI token contract — `bg-primary`,
`text-muted-foreground`, `border-input`, `ring-ring`. Works in light and dark
with no extra config.
