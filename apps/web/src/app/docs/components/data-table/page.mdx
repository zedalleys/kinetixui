## React installation

Install the package the usage below imports from:

```bash
npm i @kinetixui/ui @kinetixui/tokens
```

The project also needs Tailwind CSS 3 and the KinetixUI preset; see [Installation](/docs/installation). To own
the source instead, copy it into your project with the CLI and import from the folder it writes to:

```bash
npx @kinetixui/cli add data-table
```

## React usage

```tsx
import { DataTable, Table } from "@kinetixui/ui";
```

Styled from the KinetixUI token contract, in light and dark, with no extra configuration. For full control
of the table state, use TanStack Table's `useTable` directly with the KinetixUI `Table` parts.
