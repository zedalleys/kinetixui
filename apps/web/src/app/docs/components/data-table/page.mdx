# Data Table

Powerful table and datagrid built with TanStack Table.

<ComponentPreview name="data-table-demo" />

## Installation

```bash
npx shadcn@latest add https://kinetixui.com/r/data-table.json
```

## Usage

```tsx
import { DataTable, Table } from "@kinetixui/ui";
```

Styled entirely from the KinetixUI token contract — `bg-primary`,
`text-muted-foreground`, `border-input`, `ring-ring`. Works in light and dark
with no extra config.
