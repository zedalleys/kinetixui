# List

A composable list of rows — leading icon/avatar, title, description, trailing content.

<ComponentPreview name="list-demo" />

## Installation

```bash
npx kinetixui add list
```

## Usage

```tsx
import { List, ListItem } from "@kinetixui/ui";
```

Styled entirely from the KinetixUI token contract — `bg-primary`,
`text-muted-foreground`, `border-input`, `ring-ring`. Works in light and dark
with no extra config.
