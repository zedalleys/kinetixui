# Multi Select

<ComponentMeta />

A Combobox that keeps multiple chips — a free-entry token field with `creatable`.

<ComponentPreview name="multi-select-demo" />

## Installation

```bash
npx @kinetixui/cli add multi-select
```

## Usage

```tsx
import { MultiSelect } from "@kinetixui/ui";
```

Styled entirely from the KinetixUI token contract — `bg-primary`,
`text-muted-foreground`, `border-input`, `ring-ring`. Works in light and dark
with no extra config, and keyboard + ARIA behaviour comes from Radix — see
[Accessibility](/docs/accessibility).
