# Spinner

A lightweight loading indicator.

<ComponentPreview name="spinner-demo" />

## Installation

```bash
npx @kinetixui/cli add spinner
```

## Usage

```tsx
import { Spinner, spinnerVariants } from "@kinetixui/ui";
```

Styled entirely from the KinetixUI token contract — `bg-primary`,
`text-muted-foreground`, `border-input`, `ring-ring`. Works in light and dark
with no extra config.
