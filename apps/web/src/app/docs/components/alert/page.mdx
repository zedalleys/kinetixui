# Alert

Displays a callout for user attention.

<ComponentPreview name="alert-demo" />

## Installation

```bash
npx shadcn@latest add https://kinetixui.com/r/alert.json
```

## Usage

```tsx
import { Alert, AlertTitle, AlertDescription } from "@kinetixui/ui";
```

Styled entirely from the KinetixUI token contract — `bg-primary`,
`text-muted-foreground`, `border-input`, `ring-ring`. Works in light and dark
with no extra config.
