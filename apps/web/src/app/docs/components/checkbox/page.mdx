# Checkbox

A control that allows the user to toggle between checked and not checked. Reconciled 1:1 with design source node 54863:483.

<ComponentPreview name="checkbox-demo" />

## Installation

```bash
npx @kinetixui/cli add checkbox
```

## Usage

```tsx
import { Checkbox } from "@kinetixui/ui";
```

Styled entirely from the KinetixUI token contract — `bg-primary`,
`text-muted-foreground`, `border-input`, `ring-ring`. Works in light and dark
with no extra config, and keyboard + ARIA behaviour comes from Radix — see
[Accessibility](/docs/accessibility).
