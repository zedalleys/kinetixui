# Checkbox

A control that allows the user to toggle between checked and not checked. Design source node 54863:483.

<ComponentPreview name="checkbox-demo" />

## Installation

```bash
npx shadcn@latest add https://kinetixui.com/r/checkbox.json
```

## Usage

```tsx
import { Checkbox } from "@kinetixui/ui";
```

Styled entirely from the KinetixUI token contract — `bg-primary`,
`text-muted-foreground`, `border-input`, `ring-ring`. Works in light and dark
with no extra config.
