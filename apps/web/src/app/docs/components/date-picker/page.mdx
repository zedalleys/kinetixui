# Date Picker

A date picker — Popover + Calendar.

<ComponentPreview name="date-picker-demo" />

## Installation

```bash
npx shadcn@latest add https://kinetixui.com/r/date-picker.json
```

## Usage

```tsx
import { Calendar, Popover, Button } from "@kinetixui/ui";
```

Styled entirely from the KinetixUI token contract — `bg-primary`,
`text-muted-foreground`, `border-input`, `ring-ring`. Works in light and dark
with no extra config.
