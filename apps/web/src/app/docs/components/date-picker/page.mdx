# Date Picker

<ComponentMeta />

A text-field trigger + calendar popover, with label / helper text / error
states. Composes `Popover` + `Calendar`.

<ComponentPreview name="date-picker-demo" />

## Installation

```bash
npx @kinetixui/cli add date-picker
```

## Usage

```tsx
import { DatePicker } from "@kinetixui/ui";

<DatePicker
  label="Appointment date"
  value={date}
  onChange={setDate}
  helperText="Choose a weekday"
/>
```

For a range picker, compose `Calendar mode="range"` directly — see the
[Calendar](/docs/components/calendar) docs.

Styled entirely from the KinetixUI token contract — `bg-primary`,
`text-muted-foreground`, `border-input`, `ring-ring`. Works in light and dark
with no extra config, and keyboard + ARIA behaviour comes from Radix — see
[Accessibility](/docs/accessibility).
