# Diff Viewer

<ComponentMeta />

A side-by-side or unified text diff with gutter line numbers, built on a hand-rolled LCS line diff.

<ComponentPreview name="diff-viewer-demo" />

## Installation

```bash
npx @kinetixui/cli add diff-viewer
```

## Usage

```tsx
import { DiffViewer } from "@kinetixui/ui";
```

Styled entirely from the KinetixUI token contract — `bg-primary`,
`text-muted-foreground`, `border-input`, `ring-ring`. Works in light and dark
with no extra config, and keyboard + ARIA behaviour comes from Radix — see
[Accessibility](/docs/accessibility).
