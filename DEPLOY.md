# Deploying kinetixui.com

The site is **`apps/web`** (Next.js 15 App Router). `pnpm build:web` passes and
every route prerenders as static content. Recommended host: **Vercel**.

## What deploys where

| Target | Source | Deploy | URL |
|---|---|---|---|
| Website + registry | `apps/web` | **required** — 1 Vercel project | `kinetixui.com`, registry at `kinetixui.com/r/*.json` |
| Storybook | `apps/docs` | optional — 2nd Vercel project | `storybook.kinetixui.com` |

There is **no separate "registry" deployment** — `apps/web/public/r/*.json` is
served by the Next site. `apps/docs` is Storybook, *not* the website.

---

## 1. Push to GitHub  ✅ done

```bash
git remote add origin https://github.com/ziadfteha/kinetixui.git
git push -u origin main
```

## 2. Deploy to Vercel

### Option A — dashboard (no CLI)

1. vercel.com → **Add New… → Project** → import `ziadfteha/kinetixui`.
2. **Root Directory:** click **Edit** and select **`apps/web`**.
   ⚠️ Vercel may pre-select `apps/docs` (Storybook / Vite) — that is the wrong
   folder. It must be `apps/web`.
3. **Framework Preset:** switches to **Next.js** once the root is `apps/web`.
   Leave Build / Install commands blank — `apps/web/vercel.json` overrides them:
   - Install: `cd ../.. && pnpm install`
   - Build: `cd ../.. && pnpm build:tokens && pnpm --filter @kinetixui/ui build && pnpm --filter @kinetixui/web build`
4. **Project Name:** `kinetixui` (rename from `kinetixui-docs`).
5. **Environment Variables:** none.
6. Deploy → `kinetixui.vercel.app`.

### Option B — CLI

```bash
npm i -g vercel
cd "D:/src/strata design system/apps/web"
vercel            # first run links the project — pick the repo, Root = apps/web
vercel --prod     # production deploy → prints the live URL
```

## 3. Point kinetixui.com at Vercel (GoDaddy DNS)

In Vercel: **Project → Settings → Domains → Add** `kinetixui.com` **and**
`www.kinetixui.com`. Vercel then shows the exact records. They will be:

| Type  | Name / Host | Value                     | TTL  |
|-------|-------------|---------------------------|------|
| A     | `@`         | `76.76.21.21`             | 600  |
| CNAME | `www`       | `cname.vercel-dns.com`    | 600  |

In **GoDaddy → Domain Portfolio → kinetixui.com → DNS**:

1. **Delete** the GoDaddy "Parked" / default `A @ → <parking IP>` record and any
   `CNAME www → <parking>`.
2. **Add** the two records above (use the values Vercel shows you — the `A`
   value is stable, but always confirm in the Vercel Domains panel).
3. If GoDaddy forces a "Forwarding" rule on the root domain, remove it.
4. Save. Propagation is usually minutes, up to 48h. Vercel's Domains panel
   shows a green check when it resolves, then issues the SSL cert automatically.

> Prefer `www` as primary? Add `CNAME www → cname.vercel-dns.com`, then in
> Vercel set `www.kinetixui.com` as the primary domain and it will 308-redirect
> the apex to it (the apex still needs the `A @ → 76.76.21.21` record so the
> redirect works).

## 4. Registry endpoint

`apps/web/public/r/*.json` is served at `https://kinetixui.com/r/<name>.json`,
so `npx @kinetixui/cli add button` works the moment the domain is live.
`apps/web/public/r/` is regenerated by `pnpm build:registry`
(`node scripts/gen-registry.mjs && shadcn build …`) — the Vercel build does not
run it, so commit it (it is committed).

## 5. Optional — Storybook on `storybook.kinetixui.com`

Only if you want the Storybook playground public. It is **not** required for the
site or the registry.

1. Vercel → **Add New… → Project** → import the *same* repo again.
2. **Root Directory:** `apps/docs`. **Project Name:** `kinetixui-storybook`.
3. `apps/docs/vercel.json` sets it up: framework `storybook`, build
   `cd ../.. && pnpm build:tokens && pnpm --filter @kinetixui/docs build-storybook`,
   output `storybook-static`.
4. Deploy → `kinetixui-storybook.vercel.app`.
5. That project → Settings → Domains → add `storybook.kinetixui.com`.
6. GoDaddy → add one more record: `CNAME  storybook  cname.vercel-dns.com`.

## 6. After go-live

- `siteConfig.url` / `repo` in `apps/web/src/lib/site.ts` are already correct
  (`kinetixui.com` / `github.com/ziadfteha/kinetixui`).
- `apps/web/public/r/*.json` is committed and served as-is; regenerate with
  `pnpm build:registry` and commit when components change (Vercel does not run it).
