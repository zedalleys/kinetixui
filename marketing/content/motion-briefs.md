# Motion assets

Three, chosen because each shows something a still image genuinely cannot. Everything else on the calendar
is better as a static card, and a video of a diagram is a slower diagram.

**None is produced.** Screen recording needs a real session with a human deciding what looks right, and the
repository has no video tooling — adding one for three clips would be the "graphics SaaS" the brief warns
against. These are execution-ready shot lists.

---

## MOT-001 · Platform switching on the flagship · P1 + P2 · 18–22s

- **Why motion:** the whole point is that the *same interface* has a different real implementation per
  platform. A still shows one. The switch is the argument.
- **Product state:** homepage `#flagship`, dark theme, 1440×900, seeded so the card reads identically.
- **Shots:** (1) 0–3s the rendered React preview, still. (2) 3–6s cursor to the platform tabs. (3) 6–14s
  switch React → SwiftUI → Compose → Flutter, ~2s each, letting the code panel settle. (4) 14–18s stop on
  Flutter, scroll the source two lines so it reads as real. (5) 18–22s cut to the coverage link.
- **Captions (burned in, no voiceover):** "One interface." → "Four implementations." → "Real source, compiled
  in each platform's CI." → "Not generated from one another."
- **Format:** 1920×1080 and a 1080×1080 crop for feeds. Silent — these autoplay muted.
- **CTA:** kinetixui.com/docs/platforms · **Channel:** LinkedIn, X · **Serves:** LI-007, X-008, ART-001.

## MOT-002 · A token change moving four platforms · NEUTRAL · 20–25s

- **Why motion:** the payoff is a single edit propagating. A before/after still shows the result and hides
  the mechanism, which is the part people do not believe.
- **Product state:** local checkout, split editor, `tokens/` source left, generated outputs right.
- **Shots:** (1) 0–4s the DTCG source, one colour token visible. (2) 4–7s change the value. (3) 7–12s run
  `pnpm build:tokens`. (4) 12–20s the four generated files updating — CSS, Swift, Kotlin, Dart — in one
  `git diff`. (5) 20–25s hold on the diff showing four files, one commit.
- **Captions:** "One value." → "One build step." → "Four platforms. One commit."
- **Format:** 1920×1080, silent. Terminal at a readable size — **no tiny IDE window**.
- **CTA:** kinetixui.com/docs/tokens · **Channel:** X, LinkedIn · **Serves:** ART-002, LI-005, X-004.
- **Care:** the diff must be real. Do not stage a file that was not generated by that command.

## MOT-003 · A check failing, then passing · P1 · 15–20s

- **Why motion:** "the build fails" is an assertion until someone watches it fail.
- **Product state:** local checkout on a scratch branch.
- **Shots:** (1) 0–4s add a platform to a component in `components.manifest.json` with no source behind it.
  (2) 4–10s run `pnpm check:platform-source` — it fails, naming the component. (3) 10–14s revert. (4) 14–18s
  re-run, passes.
- **Captions:** "Claim a platform you don't implement." → "The check reads the filesystem." → "It fails
  before anyone reads it."
- **Format:** 1080×1080, silent, terminal only.
- **CTA:** kinetixui.com/docs/platforms · **Channel:** X, LinkedIn · **Serves:** LI-004, X-003, VIS-009.
- **Care:** use a scratch branch and discard it. Do not commit a deliberately false manifest entry.
