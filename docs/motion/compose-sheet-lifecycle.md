# Compose Sheet/Drawer controlled lifecycle

Material3 1.4 already supplies native entry, dragging, dialog semantics, scrim and gesture physics. The verified library defect was controlled exit: `if (!visible) return` removed the modal immediately, bypassing `SheetState.hide()`. Do not add a second slide over Material3.

Sheet now retains the modal while its native hide coroutine runs. Drawer remains a pass-through. Changing the target cancels the superseded effect and moves the same SheetState toward the latest target. Initial layout is awaited and the framework's initial show effect gets its turn before the controlled target wins, so closing during first layout cannot leave an orphan modal. Removing the component cancels the effect. Native Back can independently interrupt a hide animation while visible remains false; the effect now retries the closed target if its own job remains active, while preserving real reversal/disposal cancellation. Drag mutation is disabled during controlled exit. A regression checks the actual Android Dialog is no longer showing after a Back interruption, and fails on the prior implementation.

The existing Android animator-scale observer is read live. Controlled show/hide use a zero MotionDurationScale when animations are off; normal motion leaves the ambient duration scale untouched, including the user's nonzero scale choices. Material3 1.4's motion-scheme and show/hide timing hooks are internal, verified against that exact dependency's source. This PR does not pretend to install slow/base timing or replace native drag physics.

The existing spatial role gains an explicit Compose deviation and strict native family; no new semantic role or token is introduced. The normal timing is framework-driven; reduced motion reaches the destination without travel, rather than making a shorter journey. SwiftUI's existing deviation and all original mappings are retained. The Flutter spatial consumer is a separate PR and must be unioned structurally during integration. The nine pre-existing preference gaps are unchanged.

Verification: full Compose debug build, **130 unit/Robolectric tests**, and lint passed. Seven focused tests cover native-scale preservation, retained normal exit, reduced entry/exit through Drawer, rapid reversal/live preference changes, closing during first layout and disposal during exit. Restoring main's original Sheet makes the retained-exit assertion fail; restored sources pass again. Motion-token/native guards,49 guard tests and5 identity controls pass.

Evidence limits: the Robolectric semantics harness reliably establishes presence, retained lifetime, destination and cancellation. It did not establish a trustworthy intermediate pixel position for this native Dialog, so no midpoint geometry or motion-smoothness claim is made. Device touch/drag, hardware keyboard focus return, TalkBack and predictive Back require device/emulator acceptance. The implementation remains a draft with partial runtime evidence, not a claim of full five-platform parity. Flutter has stronger headless intermediate-geometry evidence in its separate workstream.

Public component parameters and bottom-only scope are unchanged. No npm changeset applies to this native cohort, no version is armed, and no dependency is added. Branch-specific deployments are disabled for website and Storybook. No merge, release tag, package publication or production deployment is authorized.

References: [Android's SheetState lifecycle guidance](https://developer.android.com/develop/ui/compose/components/bottom-sheets), [MotionDurationScale](https://developer.android.com/reference/kotlin/androidx/compose/ui/MotionDurationScale). The installed Material3 1.4.0 sources were checked directly; future framework versions may expose additional timing customization and require new evidence.
