# M1 local account, ownership and entitlement adapter

This is a development adapter, not production signup, authentication, billing or multi-user storage. Enable `KINETIX_CREATE_DEV=1` under `next dev` bound to loopback. All HTTP operations reject production even with that flag. A random opaque HttpOnly SameSite=Strict session cookie identifies the local account; only its hash is stored. Workspace/product ownership derives from server records. Request-supplied account IDs are not authorization.

`KINETIX_CREATE_DEV_DIR` selects the local data directory; default is `os.tmpdir()/kinetixui-create-m1`. Data lives in `studio.json`, written through a temporary file and atomic rename. Files are private to the OS account. A directory lock serializes independent adapter instances, including product creation, saved revisions and entitlement updates. A timeout fails closed. After a process crash, inspect the file/lock before manually removing an abandoned `transaction.lock`; the adapter never guesses that another live process's lock is stale. Atomic rename protects against partial writes; this is not a power-loss durability guarantee or backup service.

The free account limit is one product. Pages have no separate quota and count toward the same document size and node limits on every plan. Creation plus idempotency receipt is atomic. A retried key returns the same product. Changing the payload with the same key fails. Save checks ownership, effective entitlement, expected revision and canonical validation. Newly live IDs must start at or above the saved allocation frontier, and retired IDs stay retired. A lost save acknowledgment may be replayed without creating another revision. A newer different revision produces a conflict.

A provider-neutral entitlement seam supports a finite product limit and paid-through time. The test-only setter has no HTTP endpoint and there is no fake checkout grant. At expiration the original free product remains writable and excess products are readable/exportable but cannot save. No data is deleted. Prices, paid quantities, grace policy, selectable retained product and payment provider remain owner decisions; changing the free designation is not exposed in M1.

Before production: replace this adapter with authenticated routes, transactional database storage and RLS/tenant constraints, verified provider events, revocation/retention/backup/operations controls, plus real server/tenant/load verification. Keeping these interfaces does not establish those guarantees by itself.

Focused tests cover parallel creation across two FileStore instances, replay/conflict, foreign sessions/products, restart persistence, stale writes, exact expiration without webhook, corrupt-file preservation, invalid documents/identity replacement/rewind, production gating, origin checks and cookie settings. The dedicated Create Studio CI workflow runs for stacked draft PRs as well as main-target PRs. No deployment is performed.
