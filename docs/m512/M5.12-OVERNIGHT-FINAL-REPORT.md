## 2. Phase B — Route C reproduced, and a silent drift it cannot repair

Route C (`main` → #635 → #634 → regenerate once) was **reproduced from scratch** in a disposable
worktree rather than assumed. It produces the exact RC manifest, and the correction is **eleven**
changesets, not nine.

All **five** named negative controls were executed and every mutation restored. Three additional link
controls were run.

**The defect found.** `version-packages` runs `changeset version && node scripts/version-release-meta.mjs`.
That writer copies the curated note **verbatim** into `apps/web/src/lib/releases.ts` exactly once,
guarded by ``if (!history.includes(`version: "${version}"`))``, stripping `coverage` and stamping
`date` last. **Once the note has been activated, a later correction to it never reaches the changelog
page, and regeneration cannot repair it** — the guard sees the version already present and does
nothing. No gate compared the two afterwards, so the drift is silent and permanent.

I also found that **after a recut the coverage gates go vacuous**, which is why this hole stayed open.

**The repair (PR #638).** `scripts/check-release-note-sync.mjs` re-runs the real writer in a scratch
directory rather than parsing the activated TypeScript, then compares. On `main` today:
`check:release-note-sync ok — 4 activated notes of 6 match the changelog page.` Wired into
`check:release-notes`. Seven tests in `scripts/release/test/release-note-sync.test.mjs`, all passing,
including the load-bearing control that replaces the comparison with `if (false)` and makes the drift
invisible again.

**An error worth recording.** My first date-only control was a **silent no-op** — my regex assumed
`date` sat beside `version`, but the writer emits `date` last, so nothing was mutated and the gate
"passed" for the wrong reason. Caught by printing the entry's field order and redone with a mutation
verified to apply (1 insertion, 1 deletion). This is exactly the trap §F warns about: a passing exit
code is not proof the intended check ran.
